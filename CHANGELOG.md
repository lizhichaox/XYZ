# Changelog

## 0.0.1

First release.

- Markdown and plain text editor on macOS, iPhone, and iPad, using TextKit 2 and the system font.
- Coding, Preview, and Reading modes. ⌘E toggles Reading, and ⌘/ toggles source code mode.
- Folder workspaces on the Mac, with a source list, hidden files, live updates, rename, and move.
- Sidebar name filter (⌘⇧F) and a cancellable text search.
- One preview web view per open note, with the Mac network client entitlement so that process can start.
- Version 0.0.1 in About, with a credit link to lizhichao.com.
